## Choosing a model

Start with **FastH3** for video with synchronized audio, **FastWan** for Wan-based
video generation, or **FastMetal** for Apple Silicon. Open the matching setup guide
before choosing a checkpoint export. Check the [support matrix](/inference/support_matrix)
for runtime capabilities, then use the [cookbook](/cookbook) to configure a deployment.
